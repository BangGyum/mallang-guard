## 전투 계약

- 보호막: 피해 공식으로 계산한 피해를 먼저 흡수하고 초과분만 HP에서 뺍니다. 재충전하지 않습니다. `damage.amount`는 HP와 보호막에 준 전체 피해, 선택 필드 `shieldDamage`는 흡수한 양입니다. 기존 `src: Ref | null` 계약을 유지합니다.
- 돌진: 6초 주기로 1.2초 동안 이동 배율 1.8입니다. 이동 전에 정수 틱으로 갱신하고 둔화는 최종 이동에 곱합니다. 기절 중에는 이동·돌진 충전이 멈춥니다.
- 재생: 3초마다 최대 80 회복합니다. 죽은 적을 살리거나 최대 HP를 넘기지 않습니다. 완전히 회복된 상태에서는 준비된 회복을 유지합니다.
- 치유: 5초마다 2.5칸 안의 살아 있는 다른 적 한 명을 최대 120 회복합니다. 남은 HP 비율이 낮은 적 우선, 동점은 uid입니다. 자기 자신·죽은 적·완전히 회복된 적은 제외하고 대상이 없으면 준비 상태를 유지합니다.
- 가속: 2.4칸 안의 다른 적의 이동에 1.25배를 적용합니다. 여러 북젤리는 가장 높은 배율 하나만 적용합니다. 지원자가 죽거나 기절하거나 범위를 벗어나면 다음 이동 갱신에서 해제합니다. 적용 범위는 모두 이동 전 위치로 판정합니다.
- 소환: 8초마다 같은 경로의 자신의 뒤쪽에서 작은 젤리 한 마리를 생성하며 최대 세 번입니다. 새 uid와 기본 상태를 부여하고 `totalEnemies`를 실제 생성 수만큼 증가시킵니다. 소환자의 자식도 남아 있으면 전투를 끝내지 않습니다.
- 기절은 재생·치유·소환 충전과 발동도 멈춥니다. 능력 대상은 살아 있는 적만 사용합니다.
- 틱 순서: 상태 만료 → 돌진/가속 갱신 → 이동 → 기존 공격 방해 → 재생/치유/소환 → 아군 스킬/공격 → 사망/분열 → 승패.

## 데이터·상태·표시

`EnemyDef`는 선택 필드 `shieldHp`, `rush`, `regenerate`, `heal`, `haste`, `summon`을 추가합니다. 없는 능력은 기존 적에게 적용하지 않습니다. 양수 주기·범위·회복량·정수 소환 수·횟수, 돌진 지속 시간 ≤ 주기를 검증합니다. 소환 대상의 존재와 비행 속성 일치, 재소환·재분열 금지도 확인합니다.

`EnemyEntity`는 보호막·현재 이동 배율과 능력별 타이머·남은 소환 횟수를 갖습니다. 모든 생성 경로는 같은 `spawnEnemy`를 사용하며 기본값은 보호막/타이머/횟수 0, 이동 배율 1입니다. 수동으로 만드는 테스트 엔티티도 이 필드를 포함합니다. 저장 데이터는 스테이지 기록과 설정만 저장하므로 기존 v1 저장을 그대로 읽습니다.

보호막은 HP 위의 파란 바, 가속은 작은 상태 문구, 회복은 기존 민트 신호 파티클을 재사용합니다. `enemyHeal` 이벤트는 출처·대상 uid·실제 회복량을 전달합니다. 스테이지 선택에는 소환 자식까지 표시하고 이름과 능력을 툴팁으로 설명합니다. 머리띠·수정·방패·새싹·꽃·북·둥지·금속 날개의 실루엣으로 8종을 구분합니다.

소환자의 생존 시간에 따라 전체 적 수가 달라질 수 있습니다. 완료 검사는 고정 처치 수 대신 실제 `killed === totalEnemies`, 누수 0, 푸딩 3개로 확인합니다. 큰 맵의 분산·후방·밤밤/랑랑 배치를 새 웨이브에 맞춰 검증하며 범위와 공격 방향을 실제 대응에 사용합니다.
