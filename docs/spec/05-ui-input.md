# 05. UI와 입력 (src/ui)

## 1. 화면 흐름

```
타이틀 ──시작──▶ 전투(stage-1) ──끝──▶ 결과 ──다시하기──▶ 전투
   ▲                  │                    │
   └──── 나가기 ───── 일시정지 메뉴        └──타이틀──▶ 타이틀
```

- M4에서 타이틀 → 스테이지 선택 → 전투 경로를 추가합니다. 최초 타이틀의 "시작"은 stage-1로 가고, 같은 앱에서 스테이지를 선택한 뒤에는 그 스테이지를 시작합니다. 새로고침하면 기본 선택은 stage-1입니다.
- 스테이지 선택은 7개 지도 미리보기·등장 적·설명·최고 별을 표시합니다. 첫 스테이지와 이미 클리어한 곳, 앞 스테이지를 클리어한 곳만 열립니다. 모바일에서는 두 열로 표시하고 세로 스크롤합니다.
- 화면 전환은 `src/app/app.ts`가 맡습니다. 전투를 떠날 때 BattleSession을 `dispose()`해서 Three.js 리소스와 이벤트 리스너를 해제합니다.
- 전투 상단의 "나가기"는 준비·진행·멈춘 채 배치·카드 선택·방향 조준 중에도 바로 타이틀로 돌아갑니다. 일시정지 메뉴의 "타이틀로"와 같은 전환을 사용하며 완료 기록을 새로 만들지 않습니다. 이전 별·해금·설정은 유지하고 전투 루프·HUD·입력·효과음을 정리합니다.

## 2. 전투 HUD 배치 (가로 16:9 기준)

```
┌────────────────────────────────────────────────────────────────┐
│ [♥ 푸딩 3] [적 12/210] [WAVE 2/50]     [×2] [❚❚] [나가기]  │  ← 상단
│                                                                │
│                            (3D 보드)                            │
│                                            ┌───────────────┐   │
│                         [유닛 옆 스킬·후퇴]     │ 배치 카드 정보 │   │
│                                                                │
│ 남은 배치 5   [카드][카드][카드][카드][카드][카드]  [🌰 23 ▰▰▱]  │  ← 하단 19%
└────────────────────────────────────────────────────────────────┘
```

- 상단은 스테이지·시작 대기·전투 현황·배속/정지/나가기 그룹으로 나눠 보드를 가리는 배경을 줄입니다. 공간이 부족하면 그룹을 줄바꿈하며 버튼의 44px 이상 터치 영역을 유지합니다. 하단은 개별 배치 카드와 남은 배치·도토리 패널로 구성합니다. 크림색(`rgba(255,252,240,.93)`)과 초록 계열 글자로 산뜻한 분위기를 유지합니다.
- 크기는 `clamp()`로 화면에 맞춥니다. 기준 카드 크기는 높이 1080px 화면에서 96×104px입니다.
- 글꼴: 숫자와 제목은 Jua, 설명문은 IBM Plex Sans KR. Google Fonts `<link>`로 불러오고 fallback을 둡니다.

## 3. 컴포넌트

**상단 바** (ui/hud.ts)
- 전투 진입·재시작·다음 스테이지마다 기본 10초 준비합니다. 왼쪽 위 "3초 후 시작" 버튼은 남은 시간을 최대 3초로 줄이며, 이미 3초 이하이면 비활성화합니다. 준비가 끝나면 버튼과 남은 시간 표시를 숨깁니다.
- 준비 중에는 배치·후퇴를 할 수 있고 도토리·SP·적 이동·전투 틱은 진행하지 않습니다. 대기는 실제 시간 기준으로 배속·선택 슬로모션의 영향을 받지 않으며 일시정지·숨긴 탭에서는 멈춥니다. 화면 크기나 방향 변경으로는 멈추지 않습니다. 시작 뒤에는 기존 스테이지의 스폰 일정을 따릅니다.
- 푸딩: 하트 아이콘 + 남은 수. 줄어들 때 흔들리고 빨갛게 번쩍입니다.
- 적: `처치+누수 / 전체`.
- 웨이브: `WAVE 현재/전체`. 바뀔 때 커졌다 돌아오는 애니메이션.
- 배속 버튼: 누를 때마다 ×1 ↔ ×2. 마지막 값을 저장합니다.
- 일시정지 버튼: 일시정지 메뉴를 엽니다.
- 나가기 버튼: 직접 만든 후퇴 아이콘과 "나가기" 문구로 표시하며 현재 전투를 종료하고 타이틀로 돌아갑니다.
- 배속·정지·계속은 직접 만든 SVG 아이콘과 한국어 문구를 함께 사용하며 정지 중에는 계속하기 버튼을 초록색으로 표시합니다.

**배치 바** (ui/deployBar.ts)
- `battle.rosterView()`로 카드를 그립니다. 정렬은 비용 오름차순, 같으면 units.json 순서입니다.
- 배치 중인 유닛의 카드는 숨깁니다 (명일방주와 같음).
- 카드 구성: 초상화(인라인 SVG), 왼쪽 위 비용(도토리 아이콘 + 숫자), 아래 역할 띠(역할 색 + 한국어 역할명).

| 상태 | 표시 |
| --- | --- |
| 배치 가능 | 밝게 |
| 도토리 부족 | 채도 낮춤 + 비용 숫자 빨강 |
| 배치 인원 가득 | 전체 카드 채도 낮춤 + "남은 배치 0" 빨강 |
| 재배치 대기 | 어두운 덮개 + 남은 초 (올림) + "재배치 대기" |

- 역할 색: 선봉 `#E07A2E`, 가드 `#D33A60`, 제어 `#3E6FD1`, 스나이퍼 `#23864F`, 캐스터 `#8A5BD6`, 전술지원 `#1F9C8E`, 특수 `#5F6F80`, 서포터 `#B88500`
- 도토리 패널(오른쪽 끝): 도토리 아이콘, 큰 숫자, 수입 방식인 "처치 보상". 시간 회복 게이지는 표시하지 않습니다.

**배치 카드 정보창** (ui/rosterPanel.ts, 오른쪽 아래 고정)
- 아래 카드의 탭·클릭·Enter/Space는 `preview(unitId)`로 이름·동물·역할·초상화, 비용·재배치 대기·기본 공격력/간격·대공·기본 사거리 칸 수와 스킬 이름/설명·충전/발동 방식·시작 SP를 보여 줍니다. 아직 배치할 수 없는 카드도 정보를 볼 수 있으며 실제 배치 가능 여부는 별도로 표시합니다.
- 오른쪽 가장자리에서 8px, 배치 바 위에서 8px에 고정하고 상단 HUD 아래로 높이를 제한합니다. 작은 화면에서는 정보 영역만 스크롤합니다. 스킬 발동·후퇴 버튼은 표시하지 않습니다.
- 정보 확인은 전투 상태를 바꾸지 않습니다. 높은 칸을 누르면 방향 조준으로, 카드를 끌면 기존 드래그 배치로 이어집니다. 닫기·Esc·보드 밖 탭으로 닫으며 배치된 유닛을 누르면 유닛 조작으로 전환합니다.

**배치된 유닛의 스킬 조작창** (ui/unitPanel.ts)
- 선택한 유닛 근처에 이름·초상화·스킬 이름·SP·현재 공격력/간격과 큰 발동 버튼·작은 후퇴 버튼을 표시합니다. 긴 스킬 설명과 기본 비용은 카드 정보에서 확인합니다. 사거리와 선택 칸 표시는 유지합니다.
- 유닛 오른쪽을 우선 사용하고 가장자리에서는 왼쪽으로 옮깁니다. 양옆에 공간이 없는 좁은 세로 화면은 위·아래를 사용하며 상단 HUD·배치 바를 피하도록 제한합니다. 화면 크기 변경 시 위치를 다시 계산합니다.
- 열릴 때는 0.16초의 투명도 변화만 사용해 버튼의 위치·크기를 유지합니다. 닫기·빈 곳 탭·Esc로 닫습니다.
- **스킬 상태와 조작**: 상태·SP·게이지를 묶고, 발동 버튼은 60px 이상이며 모든 조작의 터치 영역은 44px 이상입니다.
  - 충전 중: "충전 중", `SP sp/spCost`, 청회색 게이지와 비활성 버튼.
  - 준비됨(수동): "준비 완료", 노란 게이지와 "스킬 발동" 버튼. 누르면 `activateSkill`.
  - 대상 필요: `enemyInRange` 스킬은 sim의 `skillHasTarget` 조회로 같은 대상 판정을 사용합니다. SP가 준비됐어도 대상이 없으면 "대상 대기"로 표시하고 발동 버튼을 비활성화합니다. 적이 범위에 들어오면 사용할 수 있습니다.
  - 발동 중: "발동 중", 초 단위 남은 시간, 초록색 게이지와 비활성 "스킬 사용 중" 버튼.
  - 자동 발동 스킬: 수동 버튼을 숨기고 비조작 "자동 발동" 배지와 게이지를 보여 줍니다.
- 스킬 이름과 충전/발동 방식은 버튼 위에 표시하고 전체 설명은 배치 카드 정보에 표시합니다.
- 끈적젤리·왕젤리의 방해 중에는 공격이 느려진 상태와 남은 시간을 표시합니다. 보드의 SP 아래에도 상태를 표시하며 아군 체력 바는 없습니다.
- **후퇴 버튼**: 후퇴 아이콘 + "후퇴 / 환급 없음". 누르면 바로 `retreat`. 확인 창은 없습니다.

**스킬 발동 알림** (ui/skillNotices.ts)
- `skillStart`를 받으면 해당 유닛 근처에 "토리 · 스킬 발동 / 전리품 수거"처럼 유닛 이름과 스킬 이름을 함께 띄웁니다. 자동 스킬은 "자동 발동"으로 표시하며 선택하지 않은 유닛도 알립니다.
- 유닛·스킬 팝업·다른 발동 알림과 겹침이 적은 주변 위치를 고르고, 터치와 마우스 입력을 가로채지 않습니다.
- 실제 시간 1.9초 동안 나타났다 떠오르며 사라집니다. 후퇴·전투 종료·화면 정리 시 제거합니다.

**토스트** (ui/toast.ts): `commandRejected` 이벤트의 이유를 화면 아래쪽 가운데에 1.5초 동안 띄웁니다.

| reason | 문구 |
| --- | --- |
| `noDp` | 도토리가 부족해요 |
| `limit` | 더 배치할 수 없어요 |
| `badTile` | 여기엔 놓을 수 없어요 |
| `occupied` | 이미 친구가 있어요 |
| `notReady` | 아직 준비 중이에요 |
| `skillNotReady` | 스킬이 아직 안 찼어요 |
| `noTarget` | 범위 안에 대상이 없어요 |

**일시정지 메뉴**: "계속하기", "멈춘 채 배치", "다시 시작", "타이틀로". "멈춘 채 배치"는 메뉴만 닫고 시간을 멈춰 둡니다. 이 상태에서도 배치·후퇴·스킬 명령을 적용하며 상단 "계속하기"로 전투를 이어 갑니다. 메뉴에서 Esc는 계속하기와 같습니다. Space는 메뉴를 열지 않고 일시정지를 토글합니다.

**결과 화면**
- 승리: "방어 성공!" + 남은 푸딩 수에 따른 별 1~3개 + "다음 스테이지"·"다시 하기"·"타이틀로"·"스테이지 선택". 마지막 스테이지에는 다음 버튼이 없습니다.
- 패배: "푸딩을 뺏겼어요…" + "다시 하기"·"타이틀로"·"스테이지 선택". 별은 표시하지 않습니다.
- 승리하면 클리어 여부와 최고 남은 푸딩 수를 저장합니다. 이후 패배해도 최고 기록을 지우지 않습니다. 다시 하기는 페이지를 새로 불러오지 않고 전투 상태를 초기화합니다.
- 별과 해금은 기존 v1의 `cleared`, `bestLife`에서 계산하며 저장 키와 구조를 바꾸지 않습니다.

**타이틀 화면**: "말랑방위대" 로고(Jua), 동물 8마리가 통통 튀는 줄, "시작"·"스테이지 선택"·"설정" 버튼, 하단에 작은 글씨로 버전.
- 현재 스테이지와 최고 푸딩 기록을 표시합니다. 푸딩·친구는 T3.1에서 전투와 같은 코드 생성 SVG로 교체했습니다.

## 4. 입력 상태 머신 (ui/controller.ts)

```
idle ─ 카드 선택 ─▶ preview ─ 12px 이상 끌기 ─▶ dragging
                      │                           │ 높은 칸에 놓기
                      └─ 높은 칸 누르기 ────────────▶ aiming
                                                   │ 방향 확정 → deploy
idle ◀───────────────────────────────────────────────┘
idle ─ 배치된 유닛 누르기 ─▶ selected ─ 스킬 / 후퇴 / 닫기
```

**idle**
- 카드 pointerdown 또는 Enter/Space → `preview(unitId)`. 도토리 부족·재배치 대기 중에도 정보를 볼 수 있습니다.
- 보드 탭: 그 칸에 유닛이 있으면 `selected(uid)`.
- 키보드: Space 일시정지 토글, `1`/`2` 배속, Esc는 메뉴.

**dragging(unitId)**
- 모든 친구가 놓일 수 있는 빈 보라색 고지대 칸을 초록으로 표시합니다 (`battle.checkDeploy`로 판정).
- 포인터를 따라 반투명 유닛 그림(고스트)이 움직입니다. 배치 가능한 칸 위에서는 칸 중심에 붙습니다.
- 보드 밖에서도 동일한 동물 SVG가 55% 불투명도로 포인터를 따라갑니다. 보드에 들어오면 칸 위의 3D 고스트로 이어지고 취소 시 사라집니다.
- 배치 가능 칸에서 pointerup → `aiming(unitId, tile)`.
- 그 외 위치에서 pointerup, 또는 Esc → idle.

**preview(unitId)**
- 카드의 정보창과 배치 가능한 고지대 표시를 사용하며, 탭만으로 고스트나 배치 명령을 만들지 않습니다.
- 카드에서 12px 이상 움직이면 배치 가능 여부를 검사해 dragging으로 전환합니다. 작은 터치 화면의 가로 쓸기는 목록 스크롤, 세로 끌기는 배치로 구분합니다. 배치 불가 상태에서 실제 배치를 시도할 때만 사유를 알립니다.
- 높은 칸을 누르면 aiming, 배치된 유닛을 누르면 selected로 전환합니다.

**aiming(unitId, tile)**
- 칸 위에 고스트를 세우고 상하좌우 화살표 4개를 띄웁니다. 취소 버튼(✕)도 함께 띄웁니다.
- T1.6에서는 카드를 칸에 놓은 뒤 방향 버튼을 탭하거나, 칸 중심에서 두 번째 드래그를 시작합니다. 취소 버튼은 중심에서 비켜 놓아 조준 드래그를 가리지 않습니다.
- 방향 정하기: 포인터를 누른 채 칸 중심에서 끌면, `(포인터 − 칸 중심 화면 좌표)`의 주축 방향이 dir이 됩니다.
  - 28px 미만이면 아직 미정입니다.
  - 방향이 정해지면 그 방향의 사거리를 노랗게 미리 보여 줍니다.
  - 마우스와 터치 조준 드래그는 같은 규칙을 사용합니다.
- 방향이 정해진 상태에서 pointerup → `enqueue({ type: 'deploy', unitId, tile, dir })` → idle.
- 키보드: 화살표로 방향 선택, Enter로 확정.
- ✕, Esc, 칸에서 먼 곳(3칸 이상) 탭 → idle.

**selected(uid)**
- 오른쪽 아래 캐릭터 정보창을 열고 선택한 칸과 사거리를 표시합니다.
- 스킬 버튼 → `activateSkill` (선택 유지). 후퇴 → `retreat` → idle.
- 다른 유닛 칸 탭 → 그 유닛 선택. 빈 곳 탭 / Esc → idle.
- 선택한 유닛이 사라지면(`unitRetreat`) → idle.

**슬로모션**: `dragging`, `aiming`, `selected` 동안 앱 루프 배율에 `BULLET_TIME_SCALE`(0.25)을 곱합니다. controller가 `onModeChange` 콜백으로 루프에 알려 줍니다.

**포인터 처리**
- Pointer Events만 씁니다 (마우스·터치 통합). 보드 캔버스는 `touch-action: none`.
- 카드에서 시작한 드래그는 `setPointerCapture`로 보드 위까지 이어 받습니다.
- 멀티터치는 첫 포인터만 처리합니다.

## 5. 세로 화면과 모바일

- 좁은 창이나 세로 화면에서도 회전·화면 확대 안내를 띄우지 않고 플레이합니다. 리사이즈는 전투와 준비 시간을 자동으로 멈추지 않으며, 수동으로 선택한 정지·메뉴 정지는 그대로 유지합니다.
- 폭 700px 이하에서는 상단 버튼을 줄바꿈해 시작·배속·일시정지를 화면 안에 표시하고, 모바일용 작은 카드와 초상화를 사용합니다. 카드의 가로 쓸기는 목록 스크롤, 위로 끌기는 기존 배치 입력으로 처리합니다. 상단과 겹치는 일반 배치 설명은 숨깁니다.
- 버튼 최소 터치 영역은 44×44px입니다.
- 9종 로스터가 있는 780px 이하 가로 화면에서는 배치 카드 폭을 58px로 줄여 마지막 밤밤 카드까지 바로 선택할 수 있게 합니다. 카드 높이와 최소 터치 영역은 유지합니다.
- 10종 로스터가 있는 높이 500px·폭 980px 이하 화면 또는 폭 700px 이하 화면에서는 배치 카드 폭을 50px로 줄입니다. 이름은 12px, 역할은 좌우 여백 2px와 한 줄 표시로 카드 안에 맞추며 44px 이상의 터치 영역을 유지합니다. 목록이 넘치면 가로로 스크롤합니다.
- 모바일 주소창 높이 변화에 대응하도록 `#app`은 `100dvh`를 씁니다.

## 6. 접근성

- 모든 버튼은 `<button>`이고 `aria-label`을 붙입니다 (아이콘만 있는 버튼 포함).
- `:focus-visible` 링을 표시합니다.
- 상태를 색만으로 나타내지 않습니다 (재배치 대기는 숫자, 도토리 부족은 빨간 숫자 + 채도).
- 푸딩이 1개 이하이면 경고색을 유지합니다. 푸딩 감소·웨이브 변경·배치 불가 카드 피드백은 모션 감소 설정에서 움직임을 생략합니다.
- 스킬 발동 알림은 `aria-live="polite"`로 한 번 읽습니다. `prefers-reduced-motion`에서는 팝업과 알림의 움직임을 생략합니다.
- 일시정지·결과 화면은 native dialog의 모달 포커스를 사용합니다. 열려 있는 동안 뒤쪽 HUD와 배치·배속 단축키가 동작하지 않습니다.

## 7. 저장 (src/app/save.ts)

localStorage 키는 `mallang-guard:v1` 하나에 JSON으로 저장합니다. 모든 접근은 try/catch로 감싸고, 실패해도 게임은 돌아가야 합니다.

앱 시작 때 저장 데이터를 읽고 설정 변경과 승리 시 갱신합니다. 깨진 JSON·알 수 없는 버전은 기본값으로 시작하며, 일부 필드만 잘못되었으면 유효한 필드는 유지합니다. 기본값은 배속 1, 품질 high, 볼륨 0.7, 모션 설정 null입니다.

- 타이틀·일시정지 메뉴에서 설정을 엽니다. 효과음 슬라이더/음소거/소리 확인, 화면 품질, 전투 배속, 움직임과 화면 흔들림을 즉시 적용하고 저장합니다.
- 모션 설정 null은 OS를 따르고, true는 움직임을 줄이고 흔들림을 끄며, false는 기본 움직임을 사용합니다. 저장한 선택은 OS보다 우선합니다. CSS·HUD 피드백·스킬 팝업·캐릭터·이펙트에 같은 값을 전달합니다.
- 전투 중 설정을 닫으면 일시정지 메뉴로 돌아갑니다. Esc로도 닫을 수 있으며 조작 영역은 최소 44px입니다.

```ts
interface SaveData {
  version: 1;
  settings: { speed: 1 | 2; quality: 'high' | 'low'; sfxVolume: number; reducedMotion: boolean | null };
  stages: Record<string, { cleared: boolean; bestLife: number }>;
}
```
