# 05. UI와 입력 (src/ui)

## 1. 화면 흐름

```
타이틀 ──시작──▶ 전투(stage-1) ──끝──▶ 결과 ──다시하기──▶ 전투
   ▲                  │                    │
   └──── 나가기 ───── 일시정지 메뉴        └──타이틀──▶ 타이틀
```

- v0.1에는 스테이지가 1개라 스테이지 선택 화면이 없습니다. 타이틀의 "시작"이 바로 stage-1로 갑니다. 스테이지 선택은 M4에서 추가합니다.
- 화면 전환은 `src/app/app.ts`가 맡습니다. 전투를 떠날 때 BattleSession을 `dispose()`해서 Three.js 리소스와 이벤트 리스너를 해제합니다.

## 2. 전투 HUD 배치 (가로 16:9 기준)

```
┌────────────────────────────────────────────────────────────────┐
│ [♥ 푸딩 3] [적 12/21]          [WAVE 2/5]           [×2] [❚❚]  │  ← 상단 7%
│                                                                │
│ ┌──────────┐                                                   │
│ │ 유닛 패널 │                 (3D 보드)                          │
│ │ (선택 시) │                                                   │
│ └──────────┘                                                   │
│                                                                │
│ 남은 배치 5   [카드][카드][카드][카드][카드][카드]  [🌰 23 ▰▰▱]  │  ← 하단 19%
└────────────────────────────────────────────────────────────────┘
```

- 상단 바와 하단 배치 바는 반투명 진자주(`rgba(36,28,48,.78)`) 둥근 알약 모양입니다. 목업과 같습니다.
- 크기는 `clamp()`로 화면에 맞춥니다. 기준 카드 크기는 높이 1080px 화면에서 96×104px입니다.
- 글꼴: 숫자와 제목은 Jua, 설명문은 IBM Plex Sans KR. Google Fonts `<link>`로 불러오고 fallback을 둡니다.

## 3. 컴포넌트

**상단 바** (ui/hud.ts)
- 푸딩: 하트 아이콘 + 남은 수. 줄어들 때 흔들리고 빨갛게 번쩍입니다.
- 적: `처치+누수 / 전체`.
- 웨이브: `WAVE 현재/전체`. 바뀔 때 커졌다 돌아오는 애니메이션.
- 배속 버튼: 누를 때마다 ×1 ↔ ×2. 마지막 값을 저장합니다.
- 일시정지 버튼: 일시정지 메뉴를 엽니다.

**배치 바** (ui/deployBar.ts)
- `battle.rosterView()`로 카드를 그립니다. 정렬은 비용 오름차순, 같으면 units.json 순서입니다.
- 배치 중인 유닛의 카드는 숨깁니다 (명일방주와 같음).
- 카드 구성: 초상화(인라인 SVG), 왼쪽 위 비용(도토리 아이콘 + 숫자), 아래 역할 띠(역할 색 + 한국어 역할명).

| 상태 | 표시 |
| --- | --- |
| 배치 가능 | 밝게 |
| 도토리 부족 | 채도 낮춤 + 비용 숫자 빨강 |
| 배치 인원 가득 | 전체 카드 채도 낮춤 + "남은 배치 0" 빨강 |
| 재배치 대기 | 어두운 덮개 + 남은 초 (올림) + "재배치 대기" |

- 역할 색: 선봉 `#E07A2E`, 가드 `#D33A60`, 디펜더 `#3E6FD1`, 스나이퍼 `#23864F`, 캐스터 `#8A5BD6`, 메딕 `#1F9C8E`, 특수 `#5F6F80`, 서포터 `#B88500`
- 도토리 패널(오른쪽 끝): 도토리 아이콘, 큰 숫자, 다음 1개까지의 진행 게이지 (`dpTicks / ticksPerDp`).

**유닛 패널** (ui/unitPanel.ts, 유닛을 선택했을 때 왼쪽에 표시)
- 초상화, 이름, 역할, HP 숫자와 바, 공격·방어·저지 수.
- **스킬 버튼**: 원형. 바깥 링이 SP 비율만큼 차오릅니다.
  - 충전 중: `sp/spCost` 숫자, 회색.
  - 준비됨(수동): 노랗게 빛나며 "발동". 누르면 `activateSkill`.
  - 발동 중: 남은 시간 링.
  - 자동 발동 스킬: 버튼 대신 "자동" 배지와 게이지만 표시.
- 스킬 이름과 설명(skills.json의 `description`)을 버튼 옆에 씁니다.
- **후퇴 버튼**: "후퇴 (+환급량)". 누르면 바로 `retreat`. 확인 창은 없습니다.

**토스트** (ui/toast.ts): `commandRejected` 이벤트의 이유를 화면 아래쪽 가운데에 1.5초 동안 띄웁니다.

| reason | 문구 |
| --- | --- |
| `noDp` | 도토리가 부족해요 |
| `limit` | 더 배치할 수 없어요 |
| `badTile` | 여기엔 놓을 수 없어요 |
| `occupied` | 이미 친구가 있어요 |
| `notReady` | 아직 준비 중이에요 |
| `skillNotReady` | 스킬이 아직 안 찼어요 |
| `noTarget` | 범위 안에 대상이 없어요 |

**일시정지 메뉴**: "계속하기", "다시 시작", "나가기". 일시정지 중에도 보드에는 배치할 수 있습니다 (메뉴를 닫은 일시정지 상태에서).

**결과 화면**
- 승리: "방어 성공!" + 남은 푸딩 수 + "다시 하기"·"타이틀로".
- 패배: "푸딩을 뺏겼어요…" + "다시 하기"·"타이틀로".
- 별 3개 평가는 M4에서 추가합니다.

**타이틀 화면**: "말랑방위대" 로고(Jua), 동물 8마리가 통통 튀는 줄, "시작" 버튼, 하단에 작은 글씨로 버전.

## 4. 입력 상태 머신 (ui/controller.ts)

```
                 카드 누름 (배치 가능)
   ┌──────┐ ───────────────────────────▶ ┌──────────┐
   │ idle │                              │ dragging │
   └──────┘ ◀── 빈 곳에 놓음 / Esc ─────── └────┬─────┘
     ▲  │                                      │ 배치 가능 칸에 놓음
     │  │ 유닛 있는 칸 탭                        ▼
     │  ▼                                  ┌──────────┐
   ┌──────────┐                            │  aiming  │
   │ selected │                            └────┬─────┘
   └──────────┘                                 │ 방향 정하고 손 뗌 → deploy 명령
         스킬 / 후퇴 / 다른 곳 탭 / Esc            ▼
                                               idle
```

**idle**
- 배치 가능한 카드에 pointerdown → `dragging(unitId)`. 배치 불가 카드는 흔들리고 토스트를 띄웁니다.
- 보드 탭: 그 칸에 유닛이 있으면 `selected(uid)`.
- 키보드: Space 일시정지 토글, `1`/`2` 배속, Esc는 메뉴.

**dragging(unitId)**
- 그 유닛이 놓일 수 있는 빈 칸을 초록으로 표시합니다 (`battle.checkDeploy`로 판정).
- 포인터를 따라 반투명 유닛 그림(고스트)이 움직입니다. 배치 가능한 칸 위에서는 칸 중심에 붙습니다.
- 배치 가능 칸에서 pointerup → `aiming(unitId, tile)`.
- 그 외 위치에서 pointerup, 또는 Esc → idle.

**aiming(unitId, tile)**
- 칸 위에 고스트를 세우고 상하좌우 화살표 4개를 띄웁니다. 취소 버튼(✕)도 함께 띄웁니다.
- 방향 정하기: 포인터를 누른 채 칸 중심에서 끌면, `(포인터 − 칸 중심 화면 좌표)`의 주축 방향이 dir이 됩니다.
  - 28px 미만이면 아직 미정입니다.
  - 방향이 정해지면 그 방향의 사거리를 노랗게 미리 보여 줍니다.
  - 드래그에서 바로 이어진 경우(dragging에서 손을 떼지 않은 터치)도 같은 규칙입니다.
- 방향이 정해진 상태에서 pointerup → `enqueue({ type: 'deploy', unitId, tile, dir })` → idle.
- 키보드: 화살표로 방향 선택, Enter로 확정.
- ✕, Esc, 칸에서 먼 곳(3칸 이상) 탭 → idle.

**selected(uid)**
- 유닛 패널을 열고 사거리를 표시합니다.
- 스킬 버튼 → `activateSkill` (선택 유지). 후퇴 → `retreat` → idle.
- 다른 유닛 칸 탭 → 그 유닛 선택. 빈 곳 탭 / Esc → idle.
- 선택한 유닛이 사라지면(`unitDie`, `unitRetreat`) → idle.

**슬로모션**: `dragging`, `aiming`, `selected` 동안 앱 루프 배율에 `BULLET_TIME_SCALE`(0.25)을 곱합니다. controller가 `onModeChange` 콜백으로 루프에 알려 줍니다.

**포인터 처리**
- Pointer Events만 씁니다 (마우스·터치 통합). 보드 캔버스는 `touch-action: none`.
- 카드에서 시작한 드래그는 `setPointerCapture`로 보드 위까지 이어 받습니다.
- 멀티터치는 첫 포인터만 처리합니다.

## 5. 세로 화면과 모바일

- 터치 기기에서 세로 화면이면 "가로로 돌려주세요" 안내를 화면 전체에 띄우고 자동 일시정지합니다.
- 버튼 최소 터치 영역은 44×44px입니다.
- 모바일 주소창 높이 변화에 대응하도록 `#app`은 `100dvh`를 씁니다.

## 6. 접근성

- 모든 버튼은 `<button>`이고 `aria-label`을 붙입니다 (아이콘만 있는 버튼 포함).
- `:focus-visible` 링을 표시합니다.
- 상태를 색만으로 나타내지 않습니다 (재배치 대기는 숫자, 도토리 부족은 빨간 숫자 + 채도).

## 7. 저장 (src/app/save.ts)

localStorage 키는 `mallang-guard:v1` 하나에 JSON으로 저장합니다. 모든 접근은 try/catch로 감싸고, 실패해도 게임은 돌아가야 합니다.

```ts
interface SaveData {
  version: 1;
  settings: { speed: 1 | 2; quality: 'high' | 'low'; sfxVolume: number; reducedMotion: boolean | null };
  stages: Record<string, { cleared: boolean; bestLife: number }>;
}
```
