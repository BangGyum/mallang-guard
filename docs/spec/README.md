## 확정된 결정

바꾸려면 사람(레포 주인)의 확인이 필요합니다. 구현 중에 임의로 바꾸지 않습니다.

1. **엔진 없이 Three.js + TypeScript + Vite.** Phaser, Godot, React 같은 프레임워크는 쓰지 않습니다.
2. **2.5D 구조.** 땅은 3D 타일, 캐릭터는 카메라를 향한 2D 빌보드입니다.
3. **전투 시뮬레이션은 렌더러와 완전히 분리합니다.** `src/sim`은 순수 TS로 쓰고, 30Hz 고정 틱에 결정론적으로 동작합니다.
4. **콘텐츠 수치는 전부 JSON에 둡니다** (`src/data`). 규칙 상수만 `src/sim/constants.ts`에 둡니다.
5. **캐릭터 그림은 코드로 생성합니다.** SVG 문자열을 만들어 텍스처로 굽습니다. 외부 이미지 에셋은 쓰지 않습니다.
6. **UI는 프레임워크 없이 DOM으로 만듭니다.** 3D 캔버스 위에 2D 오버레이 캔버스, 그 위에 DOM HUD를 겹칩니다.
7. **도구:** 패키지 매니저 npm, 린트·포맷 Biome, 테스트 Vitest, 배포 GitHub Pages(Actions).
8. **화면은 가로 우선**(16:9 기준)으로 만듭니다. 2026-10-09 요청에 따라 좁은 창과 세로 화면에서도 회전·화면 확대 안내나 자동 일시정지 없이 플레이합니다. 폭 700px 이하에서는 버튼을 줄바꿈하고 작은 카드와 가로 스크롤을 사용합니다.
9. **디펜스 규칙 (2026-10-07 사용자 확정):** 모든 친구는 보라색 높은 칸에 배치해 자동 공격합니다. 아군 체력·피격·사망·길 위 저지는 없고 각자 스킬을 갖습니다.
10. **v0.1 범위:** 스테이지 1개, 아군 8종, 적 3종, 스킬 8개. 이것으로 처음부터 끝까지 플레이할 수 있어야 합니다.
11. **M4 범위 (2026-10-08 요청):** 총 6개 스테이지·적 7종·별 평가·스테이지 선택과 진행 저장. 상세 규칙은 09 문서입니다.
12. **전투 아트 (2026-10-08 요청):** 산뜻한 동물·정원 분위기 위에 총·검·해머 등 무장과 전투 동작을 적용합니다. 고지대 자동 공격 규칙과 수치는 유지합니다. 상세 무장과 연출은 06 문서입니다.
13. **전투 준비와 선택 정보 (2026-10-08·09 요청):** 기본 10초 준비 후 시작하며, 왼쪽 위 "3초 후 시작" 버튼으로 대기를 줄입니다. 아래 배치 카드를 누를 때 정보가 오른쪽 아래에 고정되며, 이미 배치된 친구는 유닛 근처의 스킬·후퇴 조작창을 사용합니다. 상세 동작은 05 문서입니다.
14. **큰 맵 (2026-10-09 요청):** 기존 11×6칸의 가로·세로 타일 수를 각각 두 배로 늘린 22×12칸 stage-7을 추가합니다. stage-1~6과 캐릭터·적·스킬 수치는 유지하며, 기존 stage-6 클리어 기록으로 해금합니다.
15. **광범위 캐릭터 (2026-10-09 요청):** 기본 주변 5×5칸, 수동 스킬 중 10×10칸으로 확대하며 공격력·공격 속도가 증가하는 부엉이 밤밤을 추가합니다. 아군·스킬은 총 9종이며 기존 8종의 수치는 유지합니다. 상세 수치는 09 문서와 실제 JSON을 따릅니다.
16. **밤밤 외형 (2026-10-09 요청):** 하늘하늘한 여성 캐릭터 느낌을 적용합니다. 현재는 기존 동물 형태를 유지한 여성 부엉이로 부드러운 깃털·리본·가벼운 망토와 크림·민트·라벤더 색을 사용합니다. 관측 장비·에너지포와 전투 수치는 유지하며 상세 디자인은 06 문서를 따릅니다.
17. **정면 집중 사격 (2026-10-09 요청):** 늑대 랑랑은 정면 5×1칸에 단일 사격하며 스킬 중에는 5×3칸의 서로 다른 적 최대 3명에게 동시 사격합니다. 적이 한 명이면 한 발이고 스킬 중 공격력은 10% 감소합니다. 아군·스킬은 총 10종이며 기존 9종 수치는 유지합니다.
18. **적 15종 확장 (2026-10-09 요청):** 여러 디펜스 게임의 행동·대응 구조를 참고해 기존 7종에 돌진·마법 저항·보호막·재생·치유·가속·소환·중장갑 비행 8종을 추가합니다. 새 적은 2~7스테이지에 등장하며 적끼리 회복·가속·소환합니다. 자세한 계약은 10 문서입니다.
19. **전투 나가기와 길이 (2026-10-09 요청):** 전투 상단에 항상 보이는 "나가기" 버튼으로 타이틀에 복귀합니다. 중단 시 루프·뷰·입력·효과음을 정리하고 이전 클리어 기록을 유지합니다. 7개 스테이지는 기존 웨이브 패턴을 10회 이어 붙여 검증된 클리어 시간을 기존의 10배 이상으로 늘립니다. 개별 적의 속도·스폰 간격과 캐릭터 수치는 유지하며, 확장은 03·09 문서의 JSON 반복 설정으로 정의합니다.

20. **처치 수입과 여러 출현 지점 (2026-10-09 요청·확인):** 초기 도토리는 유지하고 이후 수입은 적 처치로만 얻습니다. 시간 회복·후퇴 환급·즉시 지급 스킬은 제거합니다. 토리의 전리품 수거는 12초 동안 사거리 안에서 아군이 처치한 적의 보상을 2개 늘립니다. 기본 보상은 적 JSON의 정수 `bounty`이며 누수는 지급하지 않고 최대 99입니다. 3~7번에 보호막·공격 방해·푸딩 2개 누수 피해의 중간보스 대장젤리를 추가합니다. 출현 지점은 1번 1곳, 2~4번 2곳, 5~7번 3곳으로 늘리고 진입 시각과 합류 지점으로 난이도를 조정합니다. 50~60웨이브·초기 배치 예산·다른 친구와 기존 적의 전투 수치는 유지합니다.

## v0.1에서 하지 않는 것

가챠, 스토리, 레벨업·장비·인벤토리, 계정·서버, 멀티플레이, 맵 에디터, 다국어, Spine 애니메이션.

## 용어

| 게임 안 표기 | 코드 식별자 | 뜻 |
| --- | --- | --- |
| 도토리 | `dp` | 배치 비용 자원. 명일방주의 DP에 해당 |
| 푸딩 | `life` | 지켜야 할 목숨. 적이 골에 들어가면 줄어듦 |
| 동물 친구 / 유닛 | `unit` | 플레이어가 배치하는 아군 |
| 젤리 / 적 | `enemy` | 경로를 따라오는 적 |
| 지상 / 고지대 | `ground` / `high` | 지상은 적 경로, 고지대는 모든 친구의 배치 칸 |
| 후퇴 | `retreat` | 배치한 유닛을 회수 (도토리 환급 없음) |
| 재배치 대기 | `cooldown` | 후퇴한 뒤 다시 배치하기까지의 시간 |
| 스킬 게이지 | `sp` | 스킬 충전량 |
| 틱 | `tick` | 시뮬레이션 1단계 = 1/30초 |
