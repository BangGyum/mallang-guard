# 09. M4 콘텐츠 확장

2026-10-08 사용자가 v0.1 보완과 M4 구현을 요청했습니다. 01~07 문서의 고지대 자동 공격·아군 체력 없음 규칙을 유지합니다. 수치의 최종 원본은 `src/data` JSON입니다.

## 범위와 진행

- 스테이지는 stage-1~7, 동물 10종, 적 16종입니다. M4의 6개에 큰 맵·광범위 캐릭터·정면 사격 캐릭터·15종 적 확장과 중간보스를 추가했습니다. 출현 지점은 1→2→3곳으로 늘립니다. 토리 스킬은 처치 보상 강화로 변경하고 다른 아군과 기존 적의 전투 수치는 유지합니다. 상세 능력·대응·참고 자료는 [10 문서](10-enemy-roster.md)입니다.
- 첫 스테이지는 항상 열려 있고, 앞 스테이지를 클리어하면 다음 스테이지가 열립니다. 이미 클리어한 스테이지는 다시 플레이할 수 있습니다.
- 모든 스테이지는 푸딩 3개로 시작합니다. 승리 시 남은 푸딩 1/2/3개가 별 1/2/3개이고 패배는 별 0개입니다. 별이 적어져도 저장된 최고 기록은 내려가지 않습니다.
- 기존 v1 저장의 `stages[id].cleared`, `bestLife`를 그대로 사용합니다. 별은 최고 푸딩 수에서, 해금은 앞 스테이지 클리어 기록에서 계산합니다.
- 타이틀에서 바로 시작하는 기존 동작을 유지하고 스테이지 선택 버튼을 추가합니다. 선택 화면은 지도 미리보기·등장 적·별·해금 조건을 보여 줍니다. 승리 결과에서 다음 스테이지로 이동할 수 있습니다.

처치 수에는 분열·소환 자식이 포함되며 소환자 처치 시점에 따라 달라집니다. 큰 맵의 후방·밤밤·랑랑 배치는 각각 490마리를 처치합니다. 시간은 준비·선택 슬로모션·일시정지를 제외한 골든 배치의 전투 시간이며, 2배속에서는 약 절반입니다. 동일 배치·입력의 단일 패턴과 비교하는 자동 테스트로 실제 클리어 시간이 10배 이상임을 확인합니다.

### 두 배 크기 정원

stage-7은 기존 11×6칸보다 가로·세로가 각각 두 배이며 전체 타일은 66개에서 264개가 됩니다. 위·아래 입구의 지상 경로는 마지막 골 한 칸에서만 합류하고 새 중앙 입구 `(0,6)`는 `(4,7)`에서 아래 경로로 합류합니다. 전방·중앙·후방의 고지대 38칸은 모두 기본 중거리 사거리의 적절한 방향으로 실제 지상 경로를 공격할 수 있습니다. 비행 경로도 위·아래로 나누고 마지막 웨이브의 까마귀 4마리는 각 경로에 2마리씩 보냅니다. 고지대 자동 공격·아군 체력 없음·캐릭터별 사거리·스킬·10초 준비 규칙을 유지합니다.

시작 도토리 25개·배치 제한 7명·푸딩 3개와 60웨이브를 사용합니다. 기본 6웨이브·36마리 패턴을 10회 진행하므로 예약 적은 360마리이고 골든 배치에서는 분열·소환 자식까지 480~490마리를 처치합니다. 소환자의 처치 시점에 따라 실제 전체 수가 달라집니다. 기존 6스테이지 클리어 기록으로 해금하고 같은 v1 형식으로 별·최고 기록을 저장합니다. 맵 크기에서 카메라·배치 가능 칸·지도 미리보기를 계산하는 기존 구현을 사용합니다.

`stage-7-clear.json`은 아래 경로의 전방·중앙과 위 경로의 후방에 전력을 나누며 `stage-7-rear-clear.json`은 두 경로의 후방에 집중합니다. 둘 다 처음에는 전방의 토리·펭펭으로 처치 수입을 얻고 30/50초에 후퇴해 재배치 대기 후 후방으로 옮깁니다. 후방 조합은 뚜껑곰의 초반 스킬을 아껴 왕젤리를 대응합니다. 두 시나리오 모두 환급 없이 실제 비용·자연 충전 스킬로 푸딩 3개를 지키며 모든 배치의 난이도 균형을 확정하는 결과는 아닙니다.

### 처치 수입과 출현 지점

초기 도토리는 아래 예산을 유지하고 이후에는 적을 처치해야 얻습니다. 토리의 전리품 수거는 12초 동안 자신의 사거리 안 처치 보상을 2개 늘리며 후퇴 환급은 없습니다. 일반 적 5~8개·작은 젤리 1개·대장젤리 12개·왕젤리 20개를 지급하며 최대 99개입니다.

| 1 | 10 | 1 | 없음 |

새 입구는 실제 `S` 타일과 예약 스폰에서 사용하는 경로로 연결합니다. 2번 정원의 아래 입구는 기본 적으로 먼저 소개하고 돌진 적은 42초로 늦춥니다. 3/5번의 추가 지상 입구는 분열 웨이브부터 사용하고 5/6번의 세 번째 입구는 비행 경로입니다. 7번 중앙 입구는 44초의 분열 무리부터 사용하며 55초의 위쪽 대장젤리, 83초의 위쪽 왕젤리로 압박을 나눕니다. 대장젤리는 각 3~7 정원의 반복 주기마다 한 번 등장합니다.

## 광범위 캐릭터 밤밤

2026-10-09 사용자 요청으로 부엉이 포격수 `owl`을 기본 로스터에 추가합니다. 외형은 크림 깃털·민트 망토·라벤더 리본의 여성 부엉이이며, 관측 장비와 에너지포를 듭니다. 보라색 고지대 배치·아군 체력 없음 규칙과 배치 제한 7명은 유지합니다.

| 항목 | 수치 |
| --- | --- |
| 배치 비용 / 재배치 | 도토리 24 / 55초 |
| 기본 공격 | 마법 공격력 320 / 1.8초 간격 / 대공 가능 |
| 기본 사거리 | 자기 칸을 포함한 주변 5×5칸 |
| 전면 포격 | 12초 동안 주변 10×10칸, 공격력 +50%(480), 공격 속도 2배(0.9초 간격) |
| 스킬 충전 | 시간 충전, 필요 SP 35 / 시작 SP 10 / 수동 발동 |

5×5는 x/y 오프셋 -2~2이며 10×10은 오른쪽 기준 -4~5입니다. 짝수 범위는 방향에 따라 회전하고 맵 밖 부분을 제외합니다. 사거리는 공격 대상을 고르는 영역이며 기존 우선순위에 따라 한 적을 공격합니다. 별도의 범위 피해 효과를 추가하지 않습니다. 이미 진행 중인 공격 쿨다운은 기존 규칙대로 유지하고 이후 공격에 새 간격을 적용합니다.

`rangeOverride` 효과는 지속 중 사거리 조회에 적용하고 만료·후퇴·재배치 시 기본 범위로 복원합니다. `stage-7-wide-clear.json`은 밤밤을 포함한 7명의 실제 비용·자연 충전 스킬로 큰 맵을 누수 없이 클리어하는 시나리오입니다. 추가된 소환·분열 압박은 아래를 바라보는 랑랑으로 대응합니다.

## 정면 집중 사격 캐릭터 랑랑

2026-10-09 사용자 요청으로 늑대 저격수 `wolf`를 기본 로스터에 추가합니다. 회청색 털과 민트 목도리, 긴 조준경 저격총을 사용하며 높은 칸에 배치합니다.

| 항목 | 수치 |
| --- | --- |
| 배치 비용 / 재배치 | 도토리 22 / 50초 |
| 기본 공격 | 물리 공격력 650 / 2.4초 간격 / 대공 가능 |
| 기본 사거리 | 자기 칸을 제외한 정면 5×1칸, 한 명에게 한 발 |
| 삼중 조준 | 12초 동안 정면 5×3칸, 서로 다른 적 최대 3명에게 동시 사격, 공격력 10% 감소(585) |
| 스킬 충전 | 시간 충전, 필요 SP 30 / 시작 SP 10 / 수동 발동 |

기본 사거리는 오른쪽 기준 x=1~5, y=0이고 스킬 중에는 y=-1~1로 넓어집니다. 적이 한 명이면 한 발, 두 명이면 두 발, 세 명 이상이면 최대 세 발입니다. 같은 줄의 여러 적도 고를 수 있고 목표까지 남은 거리·uid 순으로 선택합니다. 각 대상에게 기존 방어력을 적용한 물리 피해를 한 번 주며 빈 줄에 발사하거나 한 적에게 여러 발을 몰아주지 않습니다. 공격 간격은 스킬 중에도 2.4초이며, 만료·후퇴·재배치 시 사거리·대상 수·공격력을 복원합니다.

`stage-7-line-clear.json`은 랑랑을 포함한 7명의 실제 비용·자연 충전 스킬로 큰 맵을 누수 없이 클리어하는 시나리오입니다.

## 새 적과 타입

`EnemyDef`에 선택 필드 `description`, `split: { enemy, count }`, `disrupt: { range, intervalSec, durationSec, atkIntervalMul, targets }`를 추가합니다. 기존 적은 이 필드 없이도 동작합니다. 아트 ID는 `splitJelly`, `miniJelly`, `spitter`, `kingJelly`를 추가합니다.

- 분열젤리: 처치되면 같은 경로·현재 이동 거리에서 작은 젤리 2마리가 나옵니다. 두 번째는 0.28타일 뒤에서 출발합니다. 누수할 때는 분열하지 않습니다.
- 작은 젤리: 작고 빠르며 체력이 낮습니다. 재분열하지 않습니다. 데이터 검증에서 존재하지 않는 자식·비행 종류 불일치·재분열을 거부합니다.
- 끈적젤리: 사거리 안에서 가장 가까운 친구의 공격 간격을 잠시 늘립니다. 동점은 uid 순입니다. 아군 체력·피격·사망·도발은 추가하지 않습니다.
- 왕젤리: 높은 체력과 푸딩 3개의 누수 피해를 갖고, 최대 세 친구를 동시에 방해합니다. 감속·기절과 모든 아군 스킬로 대응할 수 있습니다.

분열 자식이 실제 생길 때 `totalEnemies`를 늘리므로 처치/전체 수는 실제 등장할 적을 셉니다. 부모 처치 이벤트 후 자식 등장 이벤트가 uid 순으로 나가며, 같은 틱의 승리 판정은 자식까지 포함합니다.

분열·소환 자식의 `enemySpawn`에는 선택 필드 `parentUid`를 붙입니다. 분열은 부모의 원거리 피격 지연과 자식 그림·HP/상태 표시 시점을 맞추고 소환은 출처를 기록합니다. 기존 예약 스폰 이벤트의 필드는 유지하며 전투 규칙에는 표시 지연을 적용하지 않습니다.

`EnemyEntity.abilityCooldown`은 정수 틱이며 기본 0입니다. 능력 적은 등장 후 한 주기 뒤부터 발사합니다. 기절 중에는 능력 충전과 발사를 멈춥니다. 사거리 안에 친구가 없으면 준비 상태를 유지합니다.

`UnitEntity.disruptedUntilTick`은 기본 0, `disruptionMul`은 기본 1입니다. 방해는 강한 배율과 긴 종료 시점을 유지하며 중첩 곱하지 않습니다. 만료 시 초기화하고 후퇴하면 제거됩니다. 공격 간격은 아군 버프 계산 후 방해 배율을 적용합니다. 이미 진행 중인 공격 쿨다운은 다시 계산하지 않습니다.

틱 순서는 상태 만료 → 돌진/가속 → 적 이동 → 적 능력·회복/소환 → 아군 스킬/공격 → 사망·분열 → 승패입니다. `unitDisrupt` 이벤트는 `{ src, uid, untilTick }`를 가지며 시각 효과와 소리에 사용합니다. 스킬 팝업·보드에는 방해 중 상태와 남은 시간을 표시합니다. 추가 능력과 공용 상태·회복 이벤트 계약은 10 문서를 따릅니다.
