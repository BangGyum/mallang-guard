## 등급과 신규 UR 노바 (T4.28)

사용자 확정: 기존 희귀 3종은 SSR을 유지하고 별도 신규 UR을 추가합니다. 등급은 고정 획득 희귀도이며 레벨/승급이나 등급별 능력치 배율은 추가하지 않습니다.

| 등급 | 합산 확률 | 친구 | 직접 영입 |
| --- | ---: | --- | ---: |
| R | 59% | 토리·굴굴·펭펭·냥기사·끈끈 | 600머니 |
| SR | 35% | 뚜껑곰·몽실·토실·밤밤·랑랑 | 600머니 |
| SSR | 5% | 루아·로크·세라 | 1,800머니 |
| UR | 1% | 노바 | 3,600머니 |

등급 안에서는 균등 추첨합니다. 모집 100/1,000·중복 환급 30·10회 미보유 보장·기본 8종/기존 10종 지급·머니/기록·저장 버전은 유지합니다. UR도 보장 대상이므로 1%는 보장 회차를 제외한 일반 추첨 확률입니다. 이미 영입한 캐릭터의 등급 변경으로 보유를 잃지 않습니다.

노바(`snowLeopard`)는 고지대·체력 없음·정면 4×3칸·지상/공중 공격을 사용합니다. 배치 23/재배치 70초, 마법 공격력 640/간격 3초/기본 폭발 반경 1칸입니다. 사건의 지평선(`eventHorizon`)은 시간 충전 55SP/배치 15SP/최초 40초이며 범위 내 적이 있어야 수동 발동합니다. 목표의 발동 시 위치에 반경 1.8칸 중력장을 4초간 고정해 일반/공중 70%·보스 25% 둔화, 끝날 때 공격력 300%(기본 1,920)의 마법 피해를 적용합니다. 목표가 사라져도 유지하고 후퇴 시 폭발 없이 취소하며 일반 공격은 계속합니다. 마저·보호막은 기존대로 적용합니다. 신규 가격과 전투 수치는 초기 가정이며 기존 13종·적·스테이지 수치는 보존합니다.

2026-10-13 승인한 세 캐릭터를 추가해 현재 아군/스킬은 13종입니다. 기존 10종의 전투 수치·기본/기존 지급·스테이지/적·보상은 유지합니다. 희귀도는 `recruitment.rareUnits`를 기준으로 표시하며 새/기존 저장에 자동 지급하지 않고 모집/직접 영입 후 실제 전투 로스터에 포함합니다.

일반 추첨은 일반 10종 합산 95%(각 9.5%), 희귀 3종 합산 5%(각 5/3%)입니다. UI의 1.67%는 반올림이며 실제 합산은 5%입니다. 미보유 10회 보장은 기존처럼 **등급별 가중치와 별도로** 미보유 균등 추첨하므로, 일반 10종을 모두 가진 계정의 보장 추첨은 희귀 미보유 중 하나를 줍니다. 신규 영입 시 보장을 초기화하고 중복 환급은 30, 직접 가격은 일반 600/희귀 1,800, 모집 비용은 100/1,000입니다. 직접 영입은 난수/보장 횟수를 유지합니다.

## 전투 보상·상점·친구 모집 (T4.24)

전투 배치용 도토리와 별도로 저장 머니를 사용합니다. 신규 프로필은 300머니와 토리·냥기사·뚜껑곰·펭펭·몽실·토실·굴굴·끈끈의 기본 8종을 받습니다. 밤밤·랑랑은 모집 또는 상점의 직접 영입으로 해금하며 기존 유효한 v1 저장은 현재 10종을 유지합니다. 현재 풀은 T4.26의 희귀 3종을 포함한 13종이며 20종 확장은 후속 콘텐츠입니다.

| 항목 | 초기 수치/계약 |
| --- | --- |
| 머니 상한 | 999,999 |
| 1회 / 10회 모집 | 100 / 1,000머니를 먼저 확인·차감 |
| 일반 모집 확률 | T4.26에서 13종: 일반 각 9.5%, 희귀 각 5/3%; 보유한 친구도 등장 |
| 중복 보상 | 30머니 환급; 캐릭터를 중복 추가하지 않음 |
| 미보유 보장 | 모집에서 새 친구 없이 9회 지나면 10번째에 미보유 중 균등 추첨; 신규 영입 시 0으로 초기화 |
| 전부 보유한 경우 | 모집 시 보장 횟수를 0으로 유지하며 중복 환급만 지급 |
| 직접 영입 | 일반 600/희귀 1,800머니; 모집 난수·보장 횟수는 유지 |
| 승리 | 스테이지 기본 보상 + 획득 별 × 40 + 첫 클리어일 때 400 |
| 패배 | 실제 처치 수 × 2, 최대 80머니 |
| 나가기 / 전투 재시작 | 중단 전투는 0머니 |

스테이지 기본 보상은 1~7번 순서로 200 / 350 / 500 / 1,200 / 1,200 / 1,800 / 2,400입니다. 예를 들어 1번을 별 3개로 처음 끝내면 720머니, 다시 끝내면 320머니이며 기존 별 3개 기록을 가진 계정이 별 1개로 이기면 이번 별 1개 보상만 받습니다. 첫 보너스는 기존 클리어 기록을 기준으로 판단하며 기록·머니를 함께 저장합니다. 잔액이 상한에 가까우면 실제 지급된 차액을 표시합니다. 전투 결과 전환의 한 번 지급 가드를 사용해 결과 화면에서 머무르거나 상점을 열어도 같은 전투 보상을 반복하지 않습니다.

상점 거래는 다음 머니·보유·보장·난수를 먼저 저장한 뒤 현재 상태에 적용합니다. 저장 실패는 모든 거래 변경을 취소하고 안내합니다. 전투 보상 저장 실패는 현재 실행의 잔액·기록을 유지하고 결과에서 안내합니다. 저장 필드의 유효성 검증·기존 이관은 03·05 문서를 따릅니다. 초기 가격/보상은 `recruitment.json`에만 두며 전투 공격·비용·SP·적·맵·공세 수치는 바꾸지 않습니다.

2026-10-08 사용자가 v0.1 보완과 M4 구현을 요청했습니다. 01~07 문서의 고지대 자동 공격·아군 체력 없음 규칙을 유지합니다. 수치의 최종 원본은 `src/data` JSON입니다.

## 범위와 진행

- 스테이지는 stage-1~7, 동물 13종, 적 22종입니다. M4의 6개에 큰 맵·광범위 캐릭터·정면 사격 캐릭터·15종 적 확장과 중간보스, 스테이지별 보스 여섯 종류를 추가했습니다. 출현 지점은 1→2→3곳으로 늘립니다. 토리 스킬은 처치 보상 강화로 변경하고 다른 아군과 기존 적의 전투 수치는 유지합니다. 상세 능력·대응·참고 자료는 [10 문서](10-enemy-roster.md)입니다.
- 첫 스테이지는 항상 열려 있고, 앞 스테이지를 클리어하면 다음 스테이지가 열립니다. 이미 클리어한 스테이지는 다시 플레이할 수 있습니다.
- 모든 스테이지는 푸딩 3개로 시작합니다. 승리 시 남은 푸딩 1/2/3개가 별 1/2/3개이고 패배는 별 0개입니다. 별이 적어져도 저장된 최고 기록은 내려가지 않습니다.
- 기존 v1 저장의 `stages[id].cleared`, `bestLife`를 그대로 사용합니다. 별은 최고 푸딩 수에서, 해금은 앞 스테이지 클리어 기록에서 계산합니다.
- 타이틀에서 바로 시작하는 기존 동작을 유지하고 스테이지 선택 버튼을 추가합니다. 선택 화면은 지도 미리보기·등장 적·별·해금 조건을 보여 줍니다. 승리 결과에서 다음 스테이지로 이동할 수 있습니다.

## 새 적과 타입

`EnemyDef`에 선택 필드 `description`, `split: { enemy, count }`, `disrupt: { range, intervalSec, durationSec, atkIntervalMul, targets }`를 추가합니다. 기존 적은 이 필드 없이도 동작합니다. 아트 ID는 `splitJelly`, `miniJelly`, `spitter`, `kingJelly`를 추가합니다.

- 분열젤리: 처치되면 같은 경로·현재 이동 거리에서 작은 젤리 2마리가 나옵니다. 두 번째는 0.28타일 뒤에서 출발합니다. 누수할 때는 분열하지 않습니다.
- 작은 젤리: 작고 빠르며 체력이 낮습니다. 재분열하지 않습니다. 데이터 검증에서 존재하지 않는 자식·비행 종류 불일치·재분열을 거부합니다.
- 끈적젤리: 사거리 안에서 가장 가까운 친구의 공격 간격을 잠시 늘립니다. 동점은 uid 순입니다. 아군 체력·피격·사망·도발은 추가하지 않습니다.
- 왕젤리: 높은 체력과 푸딩 3개의 누수 피해를 갖고, 최대 세 친구를 동시에 방해합니다. 감속·기절과 모든 아군 스킬로 대응할 수 있습니다.

분열 자식이 실제 생길 때 `totalEnemies`를 늘리므로 처치/전체 수는 실제 등장할 적을 셉니다. 부모 처치 이벤트 후 자식 등장 이벤트가 uid 순으로 나가며, 같은 틱의 승리 판정은 자식까지 포함합니다.

분열·소환 자식의 `enemySpawn`에는 선택 필드 `parentUid`를 붙입니다. 분열은 부모의 원거리 피격 지연과 자식 그림·HP/상태 표시 시점을 맞추고 소환은 출처를 기록합니다. 기존 예약 스폰 이벤트의 필드는 유지하며 전투 규칙에는 표시 지연을 적용하지 않습니다.

`EnemyEntity.abilityCooldown`은 정수 틱이며 기본 0입니다. 능력 적은 등장 후 한 주기 뒤부터 발사합니다. 기절 중에는 능력 충전과 발사를 멈춥니다. 사거리 안에 친구가 없으면 준비 상태를 유지합니다.

`UnitEntity.disruptedUntilTick`은 기본 0, `disruptionMul`은 기본 1입니다. 방해는 강한 배율과 긴 종료 시점을 유지하며 중첩 곱하지 않습니다. 만료 시 초기화하고 후퇴하면 제거됩니다. 공격 간격은 아군 버프 계산 후 방해 배율을 적용합니다. 이미 진행 중인 공격 쿨다운은 다시 계산하지 않습니다.

틱 순서는 상태 만료 → 돌진/가속 → 적 이동 → 적 능력·회복/소환 → 아군 스킬/공격 → 사망·분열 → 승패입니다. `unitDisrupt` 이벤트는 `{ src, uid, untilTick }`를 가지며 시각 효과와 소리에 사용합니다. 스킬 팝업·보드에는 방해 중 상태와 남은 시간을 표시합니다. 추가 능력과 공용 상태·회복 이벤트 계약은 10 문서를 따릅니다.
